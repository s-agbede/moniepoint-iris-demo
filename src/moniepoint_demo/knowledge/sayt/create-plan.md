# Creating a SAYT savings plan

In the Moniepoint app, open Savings, choose Add New, and select SAYT.

Choose how contributions should be calculated: a specific amount per qualifying
transaction, or a percentage. Select the transaction categories that should
trigger saving. The published instructions give transfers, airtime purchases,
and bill payments as examples.

Review the configuration and the applicable terms before confirming creation.
Once activated, the plan saves according to the chosen transaction settings.

These instructions describe a customer creating a plan in the app. They do not
establish that a support agent has permission to create or change a plan, nor do
they state that earlier transactions will be processed retroactively.
