# Managing an existing SAYT plan

Open the active SAYT plan to review activity and change settings. The activity
preview shows eight contributing transactions; the See All option opens the
longer savings history.

Customers can change which transaction categories trigger savings, including
adding or removing categories. They can also adjust the fixed contribution amount
or percentage.

A plan can be paused for a period from one to thirty days, then reactivated.
Automatic payout settings include the transfer frequency and destination account;
save the configuration after making changes.

These are general management capabilities. A customer's actual settings require
a current plan lookup. The guide does not explain the cause of a particular
missing contribution or promise that a configuration change recovers earlier
missing savings.
